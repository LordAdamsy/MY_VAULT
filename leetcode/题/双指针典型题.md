
## 0.1 **替换后的最长重复字符**

给你一个字符串 `s` 和一个整数 `k` 。你可以选择字符串中的任一字符，并将其更改为任何其他大写英文字符。该操作最多可执行 `k` 次。

在执行上述操作后，返回包含相同字母的最长子字符串的长度。

思路：

采用双指针的方法，右指针不停右移，找到最长的位置；之后如果不能够满足的话再同时左移和右移指针（因为更小的长度一定不是最终结果，且已经遍历过，不必遍历）

```C++
class Solution {
public:
    int characterReplacement(string s, int k) {
        if(s.size() == 1){return 1;}
        int* arr = new int[26]{0};
        int left = 0;
        int right = 0;
        int max_len = 0;

        while(right < s.size()){
            arr[s[right]-'A']++;
            max_len = max(max_len, arr[s[right]-'A']);
            if((right+1-max_len-left) <= k){
                right++;
            }
            else{
                arr[s[left]-'A']--;
                left++;
                right++;
            }
        }
        return right-left;
    }
};
```

## 0.2 **无重复字符的最长子串**

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串** 的长度。

思路：

双指针+hash map，hash map记录目前为止双指针间字符串的字符对应索引；
每遇到一个字符都在hash map中查找，如果不存在则加入，否则更新该索引，并移动ptr1至该索引+1的位置，同时删除原ptr1到新ptr1之间被记录在hash map中的字符/索引对即可。

```C++
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_map<char, int> str_map;
        int ptr1 = 0;
        int ptr2 = 0;
        int max_len = 0;
        while(ptr2 < s.size()){
            if(str_map.find(s[ptr2]) == str_map.end()){
                str_map[s[ptr2]] = ptr2;
                max_len = max(max_len, ptr2-ptr1+1);
            }
            else{
                int temp = str_map[s[ptr2]] + 1;
                for(int i=ptr1;i<temp;i++){
                    str_map.erase(s[i]);
                }
                ptr1 = temp;
                str_map[s[ptr2]] = ptr2;
            }
            ptr2++;
        }
        return max_len;
    }
};
```
