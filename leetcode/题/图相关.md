## 0.3 **课程表**

![[Pasted image 20250510103146.png]]

有向图 + 节点入度判定问题，从0入度节点开始，能否在处理后让所有节点的入度都为0

第一遍遍历预处理，得到每个节点的入度（下标为prerequisites\[i\]\[0\])、节点间的依赖关系（链表实现）；

第二遍遍历，将入度为0的节点压入栈中，并记录该节点已处理，避免重复压入栈；

第三遍出栈，并根据依赖关系处理后学习课程节点的入度（减1），并判断若为0则入栈；

最后遍历入度数组，若不全为0则false，否则true

```C++
class Solution {
    public:
        bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
            vector<vector<int>> arr;
            for(int i=0;i<numCourses;i++){arr.push_back(vector<int>());};
            stack<int> num_stack;
            vector<int> deg(numCourses);
            vector<int> jud(numCourses);

            for(int i=0;i<prerequisites.size();i++){
                deg[prerequisites[i][0]]++;
                arr[prerequisites[i][1]].push_back(prerequisites[i][0]);
            }  

            for(int i=0;i<prerequisites.size();i++){
                if(deg[prerequisites[i][1]] == 0 && jud[prerequisites[i][1]] == 0){
                    num_stack.push(prerequisites[i][1]);
                    jud[prerequisites[i][1]] = 1;
                }
            }

            while(!num_stack.empty()){
                int ele = num_stack.top();
                num_stack.pop();
                for(vector<int>::iterator it = arr[ele].begin();it<arr[ele].end();it++){
                    deg[*it] -= 1;
                    if(deg[*it] == 0){
                        num_stack.push(*it);
                    }
                }
            }
            
            for(int i=0;i<prerequisites.size();i++){
                if(deg[prerequisites[i][0]] > 0){
                    return false;
                }
            }
            return true;
        }
    };
```
