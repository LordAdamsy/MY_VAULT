

排序算法是计算机科学中的核心内容，其目标是将一组数据按照特定顺序（升序或降序）排列。以下是常见排序算法的详细分类、原理及适用场景，结合代码示例和性能对比：

---

### **一、排序算法分类**
| **分类依据**       | **算法类型**                                                                 |
|--------------------|-----------------------------------------------------------------------------|
| **时间复杂度**     | O(n²)：冒泡、选择、插入<br>O(n log n)：快速、归并、堆排序<br>O(n)：计数、桶、基数 |
| **稳定性**         | 稳定：冒泡、插入、归并、计数、基数<br>不稳定：选择、快速、堆排序                |
| **空间复杂度**     | 原地排序（O(1)）：冒泡、选择、插入、快速、堆排序<br>非原地排序：归并、计数、桶、基数 |

---

### **二、常见排序算法详解**

#### **1. 冒泡排序（Bubble Sort）**
- **原理**：  
  重复遍历数组，比较相邻元素，若顺序错误则交换，直到无交换发生。
- **特点**：  
  - 稳定排序  
  - 时间复杂度：最好 O(n)（已有序），最坏/平均 O(n²)  
  - 空间复杂度：O(1)  
- **代码示例**：
  ```python
  def bubble_sort(arr):
      n = len(arr)
      for i in range(n):
          swapped = False
          for j in range(0, n-i-1):
              if arr[j] > arr[j+1]:
                  arr[j], arr[j+1] = arr[j+1], arr[j]
                  swapped = True
          if not swapped:  # 提前终止优化
              break
      return arr
  ```

---

#### **2. 选择排序（Selection Sort）**
- **原理**：  
  每次从未排序部分选择最小（或最大）元素，放到已排序部分的末尾。
- **特点**：  
  - 不稳定排序  
  - 时间复杂度：O(n²)  
  - 空间复杂度：O(1)  
- **代码示例**：
  ```python
  def selection_sort(arr):
      n = len(arr)
      for i in range(n):
          min_idx = i
          for j in range(i+1, n):
              if arr[j] < arr[min_idx]:
                  min_idx = j
          arr[i], arr[min_idx] = arr[min_idx], arr[i]
      return arr
  ```

---

#### **3. 插入排序（Insertion Sort）**
- **原理**：  
  将未排序元素逐个插入到已排序部分的正确位置。
- **特点**：  
  - 稳定排序  
  - 时间复杂度：最好 O(n)（已有序），最坏/平均 O(n²)  
  - 空间复杂度：O(1)  
- **适用场景**：小规模数据或近乎有序的数据。
- **代码示例**：
  ```python
  def insertion_sort(arr):
      for i in range(1, len(arr)):
          key = arr[i]
          j = i-1
          while j >=0 and key < arr[j]:
              arr[j+1] = arr[j]
              j -= 1
          arr[j+1] = key
      return arr
  ```

---

#### **4. 快速排序（Quick Sort）**
- **原理**：  
  分治法思想：  
  1. 选择一个基准元素（pivot）；  
  2. 将数组分为两部分，小于基准的放左边，大于基准的放右边；  
  3. 递归处理左右子数组。
- **特点**：  
  - 不稳定排序  
  - 时间复杂度：平均 O(n log n)，最坏 O(n²)（已有序时）  
  - 空间复杂度：O(log n)（递归栈）  
- **优化**：随机选择基准或三数取中法避免最坏情况。
- **代码示例**：
  ```python
  def quick_sort(arr):
      if len(arr) <= 1:
          return arr
      pivot = arr[len(arr)//2]  # 选择中间元素为基准
      left = [x for x in arr if x < pivot]
      middle = [x for x in arr if x == pivot]
      right = [x for x in arr if x > pivot]
      return quick_sort(left) + middle + quick_sort(right)
  ```

---

#### **5. 归并排序（Merge Sort）**
- **原理**：  
  分治法思想：  
  1. 将数组递归拆分为子数组，直到每个子数组只有一个元素；  
  2. 合并相邻子数组并排序。
- **特点**：  
  - 稳定排序  
  - 时间复杂度：O(n log n)  
  - 空间复杂度：O(n)  
- **代码示例**：
  ```python
  def merge_sort(arr):
      if len(arr) <= 1:
          return arr
      mid = len(arr) // 2
      left = merge_sort(arr[:mid])
      right = merge_sort(arr[mid:])
      return merge(left, right)
  
  def merge(left, right):
      result = []
      i = j = 0
      while i < len(left) and j < len(right):
          if left[i] < right[j]:
              result.append(left[i])
              i += 1
          else:
              result.append(right[j])
              j += 1
      result.extend(left[i:])
      result.extend(right[j:])
      return result
  ```

---

#### **6. 堆排序（Heap Sort）**
- **原理**：  
  1. 将数组构建为最大堆（或最小堆）；  
  2. 依次取出堆顶元素（最大值），与末尾元素交换并调整堆。
- **特点**：  
  - 不稳定排序  
  - 时间复杂度：O(n log n)  
  - 空间复杂度：O(1)  
- **代码示例**：
  ```python
  def heapify(arr, n, i):
      largest = i
      left = 2 * i + 1
      right = 2 * i + 2
      if left < n and arr[left] > arr[largest]:
          largest = left
      if right < n and arr[right] > arr[largest]:
          largest = right
      if largest != i:
          arr[i], arr[largest] = arr[largest], arr[i]
          heapify(arr, n, largest)
  
  def heap_sort(arr):
      n = len(arr)
      # 构建最大堆
      for i in range(n//2 -1, -1, -1):
          heapify(arr, n, i)
      # 逐个提取元素
      for i in range(n-1, 0, -1):
          arr[i], arr[0] = arr[0], arr[i]
          heapify(arr, i, 0)
      return arr
  ```

### **三、非比较排序**

#### **1. 计数排序（Counting Sort）**
- **原理**：  
  统计每个元素的出现次数，按顺序累加后输出。
- **适用条件**：数据范围有限且为整数。
- **时间复杂度**：O(n + k)（k为数据范围）

#### **2. 桶排序（Bucket Sort）**
- **原理**：  
  将数据分到有限数量的桶中，每个桶单独排序后合并。
- **适用条件**：数据均匀分布。

#### **3. 基数排序（Radix Sort）**
- **原理**：  
  按位数从低位到高位依次排序（稳定排序）。
- **适用条件**：整数或字符串。

### **四、性能对比**
| **算法**     | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 | 适用场景                     |
|-------------|--------------|--------------|----------|--------|----------------------------|
| 冒泡排序     | O(n²)        | O(n²)        | O(1)     | 稳定   | 教学或小规模数据              |
| 快速排序     | O(n log n)   | O(n²)        | O(log n) | 不稳定 | 大规模通用数据（需优化基准选择） |
| 归并排序     | O(n log n)   | O(n log n)   | O(n)     | 稳定   | 大数据且需稳定性              |
| 堆排序       | O(n log n)   | O(n log n)   | O(1)     | 不稳定 | 内存受限的大数据              |
| 计数排序     | O(n + k)     | O(n + k)     | O(k)     | 稳定   | 整数且范围小（如年龄、分数）    |

---

### **五、如何选择排序算法？**
1. **数据规模**：  
   - 小数据（n ≤ 1000）：插入排序（简单且对近乎有序数据高效）。  
   - 大数据：快速排序（默认选择）、归并排序（需稳定性）或堆排序（内存敏感）。

2. **数据特性**：  
   - 近乎有序：插入排序或优化后的冒泡排序。  
   - 范围有限的整数：计数排序或基数排序。

3. **稳定性要求**：  
   - 需要稳定：归并排序、计数排序。  
   - 无需稳定：快速排序、堆排序。

---

### **六、总结**
- **比较排序**：通用性强，但时间复杂度下限为 O(n log n)。  
- **非比较排序**：特定场景下更快，但适用条件严格。  
- **实际应用**：Python内置的 `sorted()` 和 `list.sort()` 使用 **Timsort**（归并排序与插入排序的混合算法），兼顾稳定性和效率。
