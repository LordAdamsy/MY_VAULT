### 0.1.1 **一、冒泡排序（Bubble Sort）**
#### 0.1.1.1 **思路**：
- 重复遍历数组，依次比较相邻元素，若顺序错误则交换。
- 每次遍历将最大元素“冒泡”到末尾。

#### 0.1.1.2 **时间复杂度**：
- 平均/最坏：$O(n^2)$
- 最好（已排序）：$O(n)$

#### 0.1.1.3 **代码**：
```cpp
template<typename T>
void bubbleSort(vector<T>& arr) {
    int n = arr.size();
    for (int i = 0; i < n-1; ++i) {
        bool swapped = false;
        for (int j = 0; j < n-i-1; ++j) {
            if (arr[j] > arr[j+1]) {
                swap(arr[j], arr[j+1]);
                swapped = true;
            }
        }
        if (!swapped) break; // 提前终止优化
    }
}
```

### 0.1.2 **二、选择排序（Selection Sort）**
#### 0.1.2.1 **思路**：
- 每次遍历找到未排序部分的最小元素，与未排序部分的起始位置交换。

#### 0.1.2.2 **时间复杂度**：
- 始终 $O(n^2)$

#### 0.1.2.3 **代码**：
```cpp
template<typename T>
void selectionSort(vector<T>& arr) {
    int n = arr.size();
    for (int i = 0; i < n-1; ++i) {
        int minIdx = i;
        for (int j = i+1; j < n; ++j) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        swap(arr[i], arr[minIdx]);
    }
}
```

### 0.1.3 **三、插入排序（Insertion Sort）**
#### 0.1.3.1 **思路**：
- 将数组分为已排序和未排序部分，逐个将未排序元素插入到已排序部分的正确位置。

#### 0.1.3.2 **时间复杂度**：
- 平均/最坏：$O(n^2)$
- 最好（已排序）：$O(n)$

#### 0.1.3.3 **代码**：
```cpp
template<typename T>
void insertionSort(vector<T>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; ++i) {
        T key = arr[i];
        int j = i-1;
        while (j >= 0 && arr[j] > key) {
            arr[j+1] = arr[j];
            --j;
        }
        arr[j+1] = key;
    }
}
```

### 0.1.4 **四、快速排序（Quick Sort）**
#### 0.1.4.1 **思路**：
- **分治法**：选取基准值（pivot），将数组分为小于基准和大于基准的两部分，递归排序子数组。

#### 0.1.4.2 **时间复杂度**：
- 平均：$O(n \log n)$
- 最坏（已排序）：$O(n^2)$

#### 0.1.4.3 **代码**：
```cpp
template <typename T>

void quick_sort(vector<T>& arr, int left, int right){
    if(left >= right){return;}
    T key = arr[right];
    int ptr1 = left;
    int ptr2 = right;
    while(ptr1 < ptr2){
        while(arr[ptr1] <= key && ptr1 < ptr2){
            ptr1++;
        }
        if(ptr1 < ptr2){
            arr[ptr2] = arr[ptr1];
        }
        while(arr[ptr2] >= key && ptr1 < ptr2){
            ptr2--;
        }
        if(ptr1 < ptr2){
            arr[ptr1] = arr[ptr2];
        }
    }
    arr[ptr1] = key;
    quick_sort(arr, left, ptr1-1);
    quick_sort(arr, ptr1+1, right);
}

// 调用示例：
vector<int> arr = {10, 7, 8, 9, 1, 5};
quickSort(arr, 0, arr.size()-1);
```

### 0.1.5 **五、归并排序（Merge Sort）**
#### 0.1.5.1 **思路**：
- **分治法**：将数组分为两半，递归排序后合并两个有序子数组。

#### 0.1.5.2 **时间复杂度**：
- 始终 $O(n \log n)$

#### 0.1.5.3 **代码**：
```cpp
template<typename T>
void merge(vector<T>& arr, int left, int mid, int right) {
    vector<T> temp(right - left + 1);
    int i = left, j = mid+1, k = 0;
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
        }
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    for (int p = 0; p < k; ++p) {
        arr[left + p] = temp[p];
    }
}

template<typename T>
void mergeSort(vector<T>& arr, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid+1, right);
    merge(arr, left, mid, right);
}
```

### 0.1.6 **六、堆排序（Heap Sort）**
#### 0.1.6.1 **思路**：
- 构建最大堆，重复将堆顶元素（最大值）与末尾元素交换，并调整堆。

#### 0.1.6.2 **时间复杂度**：
- 始终 $O(n \log n)$

#### 0.1.6.3 **代码**：
```cpp
template<typename T>
void heapify(vector<T>& arr, int n, int i) {
    int largest = i;
    int left = 2*i + 1;
    int right = 2*i + 2;
    if (left < n && arr[left] > arr[largest]) {
        largest = left;
    }
    if (right < n && arr[right] > arr[largest]) {
        largest = right;
    }
    if (largest != i) {
        swap(arr[i], arr[largest]);
        heapify(arr, n, largest);
    }
}

template<typename T>
void heapSort(vector<T>& arr) {
    int n = arr.size();
    // 构建最大堆
    for (int i = n/2 - 1; i >= 0; --i) {
        heapify(arr, n, i);
    }
    // 逐个提取最大值
    for (int i = n-1; i > 0; --i) {
        swap(arr[0], arr[i]);
        heapify(arr, i, 0);
    }
}
```

### 0.1.7 **七、希尔排序（Shell Sort）**
#### 0.1.7.1 **思路**：
- 改进的插入排序，通过分组间隔递减的插入排序逐步使数组基本有序。

#### 0.1.7.2 **时间复杂度**：
- 平均：$O(n \log n)$到 $O(n^2)$（取决于间隔序列）

#### 0.1.7.3 **代码**：
```cpp
template<typename T>
void shellSort(vector<T>& arr) {
    int n = arr.size();
    for (int gap = n/2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; ++i) {
            T temp = arr[i];
            int j;
            for (j = i; j >= gap && arr[j - gap] > temp; j -= gap) {
                arr[j] = arr[j - gap];
            }
            arr[j] = temp;
        }
    }
}
```

### 0.1.8 **八、计数排序（Counting Sort）**
#### 0.1.8.1 **思路**：
- 适用于整数且范围较小的数据。统计每个元素的出现次数，按顺序重建数组。

#### 0.1.8.2 **时间复杂度**：
- $O(n + k)$（$k$为数据范围）

#### 0.1.8.3 **代码**：
```cpp
void countingSort(vector<int>& arr) {
    if (arr.empty()) return;
    int maxVal = *max_element(arr.begin(), arr.end());
    vector<int> count(maxVal + 1, 0);
    for (int num : arr) ++count[num];
    int idx = 0;
    for (int i = 0; i <= maxVal; ++i) {
        while (count[i]-- > 0) {
            arr[idx++] = i;
        }
    }
}
```

### 0.1.9 **九、基数排序（Radix Sort）**
#### 0.1.9.1 **思路**：
- 按位数从低位到高位依次进行稳定排序（通常用计数排序）。

#### 0.1.9.2 **时间复杂度**：
- $O(d \cdot (n + k))$（$d$为最大位数，$k$为基数）

#### 0.1.9.3 **代码**：
```cpp
void countingSortForRadix(vector<int>& arr, int exp) {
    vector<int> output(arr.size());
    vector<int> count(10, 0);
    for (int num : arr) ++count[(num / exp) % 10];
    for (int i = 1; i < 10; ++i) count[i] += count[i-1];
    for (int i = arr.size()-1; i >= 0; --i) {
        output[count[(arr[i]/exp)%10] - 1] = arr[i];
        --count[(arr[i]/exp)%10];
    }
    arr = output;
}

void radixSort(vector<int>& arr) {
    if (arr.empty()) return;
    int maxVal = *max_element(arr.begin(), arr.end());
    for (int exp = 1; maxVal/exp > 0; exp *= 10) {
        countingSortForRadix(arr, exp);
    }
}
```

### 0.1.10 **十、桶排序（Bucket Sort）**
#### 0.1.10.1 **思路**：
- 将数据分到有限数量的桶中，每个桶单独排序后合并。

#### 0.1.10.2 **时间复杂度**：
- 平均：$O(n + k)$（$k$为桶数）

#### 0.1.10.3 **代码**：
```cpp
void bucketSort(vector<float>& arr) {
    int n = arr.size();
    vector<vector<float>> buckets(n);
    for (float num : arr) {
        int bucketIdx = n * num; // 假设输入在 [0,1) 范围内
        buckets[bucketIdx].push_back(num);
    }
    for (auto& bucket : buckets) {
        sort(bucket.begin(), bucket.end());
    }
    int idx = 0;
    for (auto& bucket : buckets) {
        for (float num : bucket) {
            arr[idx++] = num;
        }
    }
}
```

### 0.1.11 **总结对比**
| **算法**       | **时间复杂度**       | **空间复杂度** | **稳定性** | **适用场景**               |
|----------------|----------------------|----------------|------------|---------------------------|
| 冒泡排序       | $O(n^2)$| $O(1)$| 稳定       | 小规模数据或教学           |
| 选择排序       | $O(n^2)$| $O(1)$| 不稳定     | 简单实现                   |
| 插入排序       | $O(n^2)$| $O(1)$| 稳定       | 小规模或基本有序数据       |
| 快速排序       | $O(n \log n)$| $O(\log n)$| 不稳定     | 通用排序，平均性能最佳     |
| 归并排序       | $O(n \log n)$| $O(n)$| 稳定       | 需要稳定排序或外部排序     |
| 堆排序         | $O(n \log n)$| $O(1)$| 不稳定     | 原地排序，内存受限场景     |
| 希尔排序       | $O(n \log n)$~$O(n^2)$| $O(1)$| 不稳定     | 中等规模数据               |
| 计数排序       | $O(n + k)$| $O(k)$| 稳定       | 整数且范围小               |
| 基数排序       | $O(d(n + k))$| $O(n + k)$| 稳定       | 多位数整数或字符串         |
| 桶排序         | $O(n + k)$| $O(n + k)$| 稳定       | 均匀分布的数据             |

**注**：实际开发中优先使用标准库的 `std::sort`（通常为快速排序+插入排序混合优化）。
